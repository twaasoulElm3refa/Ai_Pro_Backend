1. Executive Summary
====================

الحكم النهائي: التدفق الحالي غير جاهز للإنتاج المالي بصورته الحالية.

الراوتات الأساسية موجودة، وملكية order-status محمية جيداً بـ auth:sanctum وuser_id، وتوجد unique constraints مفيدة على payments.idempotency_key وpayments.paypal_order_id وpayments.transaction_id. كما أن شحن المحفظة وتحديث Payment وإنشاء WalletTransaction موجودة في DB::transaction واحدة، وهذا أساس جيد.

لكن توجد فجوات تمنع اعتبار الرصيد آمناً:

1) توقيع Webhook يُتخطى بالكامل عندما يكون PAYPAL_MODE=sandbox، بينما البيئة الحالية Sandbox. أي طلب يستطيع محاكاة PAYMENT.CAPTURE.COMPLETED وشحن الرصيد إذا عرف PayPal Order ID أو custom_id.
2) قبل الشحن لا يتم التحقق من status داخل resource ولا amount ولا currency ولا custom_id ولا reference_id ولا payee/merchant_id.
3) Payment لا يعرّف cast لـ gateway_response رغم حفظ arrays فيه؛ هذا قد ينتج Array to string conversion أو بيانات JSON غير صالحة وفشل التدفق.
4) استجابة capturePaymentOrder هي Order representation، لكن الكود يمررها كأنها Capture resource؛ لذلك transaction_id قد يصبح PayPal Order ID بدلاً من Capture ID الحقيقي.
5) لا يرسل PayPal-Request-Id عند create/capture، فتكرار CHECKOUT.ORDER.APPROVED أو timeout غير محمي بطبقة idempotency لدى PayPal.
6) لا يوجد unique على wallet_transactions.payment_id، ولا سجل فريد لـ webhook event id، ولا wallet_credited فعلياً.
7) البريد يُدفع إلى Redis داخل transaction مع after_commit=false؛ فشل enqueue قد يعمل rollback للدفع، والعكس: قد يبدأ البريد قبل commit أو يُرسل ثم يفشل commit.
8) balance وpoints حقول 32-bit integer. مع amount * 1,000,000 يحدث overflow بعد نحو 4,294.96 USD في unsigned wallet.balance، رغم أن payments.amount يسمح نظرياً حتى 999,999.99.
9) polling لا ينتهي فعلياً عند pending/approved لأن return يسبق فحص MAX_ATTEMPTS، وقد تتداخل طلبات setInterval.
10) APP_URL محلي بينما الواجهة تستخدم production host ثابتاً؛ return_url وcancel_url الناتجان حالياً محليان، وWebhook لا يستطيع الوصول إلى localhost.

مصدر الحقيقة النهائي ليس success redirect. المصدر الصحيح هو حالة Capture=COMPLETED التي وصلت من PayPal عبر استجابة server-to-server موثقة أو Webhook صحيح التوقيع، بعد مطابقة الهوية والمبلغ والعملة والمستفيد. Webhook وسيلة إشعار؛ الحقيقة هي Capture الموثق نفسه. يجب اعتماد أول قناة موثوقة تؤكد COMPLETED، ثم جعل القناة الأخرى idempotent.

التوصية: عدم تفعيل Live قبل تطبيق إصلاحات Critical/High، إضافة الاختبارات المالية والتزامن، وتشغيل reconciliation للطلبات approved/pending.

3. Complete Wallet Deposit Flow
================================

التدفق الحالي كما ينفذه الكود:

1) charge.vue ينشئ UUID في idempotencyKey، يقرأ auth_token من localStorage، ويرسل:
   POST https://pro.aiarabic.com/api/v1/deposit/pay
   { amount, description, idempotency_key }

2) DepositController@create يتحقق inline من amount numeric|min:1، description<=255، وidempotency_key اختياري.

3) يضيف user_id ثم يستدعي PayPalWalletServices@pay.

4) constructor للخدمة يطلب PayPal access token فوراً، حتى قبل أن تحتاج الميثود اتصالاً فعلياً.

5) pay يحسب idempotency hash. إذا لم يرسل العميل key، يدمج user+amount+تاريخ اليوم، ما يعيد استخدام أي شحنة حقيقية ثانية بنفس المبلغ في نفس اليوم.

6) يبحث عن pending/approved موجود. إذا كان له paypal_order_id، يستدعي showOrderDetails ويستخرج approve link.

7) وإلا يبدأ DB::transaction، يقفل Payment الموجود بـ lockForUpdate أو ينشئ Payment pending.

8) داخل transaction نفسها يتصل بـ PayPal createOrder، ويضع:
   - intent=CAPTURE
   - reference_id = local payment id
   - custom_id = wallet_topup:{local payment id}
   - currency/value من Payment
   - return_url/cancel_url من APP_URL

9) يحفظ paypal_order_id وgateway_response، ويعيد approval_url للواجهة.

10) charge.vue يحول window.location إلى approval_url.

11) بعد موافقة المستخدم، PayPal يعيده إلى /wallet/success?token=PAYPAL_ORDER_ID.

12) DepositController@success يستدعي service@success. الخدمة لا تسأل PayPal عن حالة الطلب؛ يكفي أن token يطابق صفاً محلياً، فتغيّر pending إلى approved.

13) controller يحول المستخدم دائماً إلى /en/Deposit/waiting?order_id=LOCAL_ID.

14) WaitingDeposit.vue يبدأ GET order-status فوراً ثم كل 5 ثوانٍ.

15) عند CHECKOUT.ORDER.APPROVED، WebhookController يستخرج resource.id، يحدد Payment ونوعه، ثم PayPalWalletServices@onOrderApproved ينفذ capturePaymentOrder.

16) إذا كانت استجابة Order capture ذات status=COMPLETED، يمرر الاستجابة كلها إلى onCaptureCompleted.

17) PAYMENT.CAPTURE.COMPLETED المنفصل يمر أيضاً إلى onCaptureCompleted، ولكن كـ Capture resource.

18) onCaptureCompleted يقفل Payment، يفحص type وwallet_credited/status، ينشئ/يجلب Wallet، يحسب points=amount*1,000,000، يزيد balance، يحدّث Payment completed، ينشئ WalletTransaction، ويعمل queue للبريد؛ كل ذلك داخل transaction.

19) polling يرى completed، يمسح interval، وينقل المستخدم إلى /{lang}/deposit/success.

ترتيب الأحداث ليس مضموناً:
- webhook قبل redirect: Payment قد ينتقل pending -> completed مباشرة، ثم success يرى completed.
- redirect قبل webhook: pending -> approved -> completed لاحقاً.
- المستخدم لا يرجع: يمكن أن يكتمل بالدفع وwebhook وحدهما.
- غياب CHECKOUT.ORDER.APPROVED مع وجود Capture completed: حدث completed يجب أن يكفي إذا كان صحيح التوقيع ومطابقاً.


4. Controller Analysis
=======================

DepositController@create (lines 21-45)
- صحيح: auth على الراوت؛ user_id يأتي من authenticated user؛ response يعيد local order_id وليس PayPal ID.
- خطأ: validation inline؛ لا يوجد FormRequest. العبارة المطلوبة: غير موجود أو لم يتم العثور عليه.
- خطأ: idempotency_key اختياري، ولا يوجد payload-conflict check.
- خطأ: يسمح بأكثر من منزلتين عشريتين وdescription حتى 255 بينما PayPal Purchase Unit description حدها 127.
- خطأ: catch يخفي الاستثناء بلا Log، ويحول conflict/validation/gateway errors كلها إلى 500.

DepositController@success (lines 48-78)
- لا يتحقق من PayPal status أو amount/currency/custom_id.
- token وحده يجعل الحالة approved؛ redirect ليس دليلاً على الموافقة.
- اللغة hard-coded إلى en.
- الأخطاء ترجع JSON في browser flow بدلاً من failed page.

DepositController@cancel (lines 81-91)
- يرجع JSON في صفحة المتصفح.
- لا توجد صفحة cancel مستقلة في router: غير موجود أو لم يتم العثور عليه.
- Payment يظل pending، وقد يعاد استخدامه لاحقاً.

DepositController@orderStatus (lines 94-112)
- حماية IDOR صحيحة: where id + where user_id.
- query جديد يقرأ آخر committed state؛ fresh() غير ضروري هنا.
- لا يقيّد type=wallet_deposit.
- يعيد status/amount/order_id فقط؛ currency وpaid_at غير موجودين.
- لا يسرب gateway_response أو payer_email أو paypal_order_id؛ هذه نقطة جيدة.
- يمسح wallet/transaction caches في كل poll حتى pending، ما يزيد الحمل ويخفي مسؤولية invalidation داخل مسار commit.

Resources/Transformers للإيداع
- غير موجود أو لم يتم العثور عليه. الردود مكتوبة يدوياً.


5. Service Analysis
====================

PayPalWalletServices::__construct (22-27)
- يجلب access token eagerly. WebhookController يحقن خدمتي PayPal، لذلك قد يحدث اتصالان OAuth قبل معالجة body.
- الأفضل lazy provider أو verifier مستقل.

pay (29-111)
- unique DB موجود على idempotency_key وpaypal_order_id.
- pre-check ثم lockForUpdate محاولة جيدة، لكن lock على صف غير موجود لا يضمن منع insert race على كل قواعد البيانات؛ unique هو آخر دفاع.
- نفس idempotency key مع مبلغ مختلف يعيد الطلب القديم بدلاً من 409.
- fallback اليومي يمنع شحنتين مقصودتين بنفس المبلغ في اليوم.
- reuse لـ approved/completed/failed قد يبحث عن approve link لم يعد موجوداً.
- PayPal createOrder واستدعاء showOrderDetails يحدثان أحياناً داخل DB transaction؛ الشبكة تطيل القفل، وrollback لا يستطيع حذف Order الذي أُنشئ خارج DB.
- لا يوجد PayPal-Request-Id رغم دعم package الحالي withIdempotencyKey().

success (113-144)
- DB lock جيد.
- completed idempotent.
- pending -> approved غير موثق من PayPal.
- approved حالة مؤقتة فقط؛ لا تشحن الرصيد.

handleWebhook (146-161)
- event allowlist داخل match جيد.
- لا يوجد حفظ payload event ID أو event processing status.

onOrderApproved (163-220)
- resource.id هو PayPal Order ID الصحيح لـ CHECKOUT.ORDER.APPROVED.
- يتحقق من type.
- لا يقفل Payment قبل capture ولا يستخدم PayPal-Request-Id.
- لا يتحقق من status=APPROVED أو purchase_units fields.
- لا يغيّر local status إلى approved من webhook.
- عند COMPLETED يمرر Order response إلى handler يتوقع Capture resource.

onCaptureCompleted (222-356)
- related_ids.order_id هو المسار الأساسي الصحيح لحدث Capture.
- supplementary_data.related_ids.paypal_order_id ليس حقلاً موثقاً هنا؛ fallback غير موثوق.
- custom_id مفيد، لكن يجب مطابقته لا استخدامه فقط للبحث.
- لا يفحص resource.status=COMPLETED.
- لا يفحص amount/currency/payee/reference/custom.
- wallet_credited غير موجود في schema ولا يتم تعيينه.
- DB transaction تشمل الرصيد وPayment وWalletTransaction؛ rollback المالي جيد من حيث التجميع.
- firstOrCreate لا يرى soft-deleted wallet؛ unique(user_id) يمنع إنشاء صف بديل.
- Wallet نفسه غير مقفول، فتزامن شحنتين مختلفتين للمستخدم قد يجعل balance_before/after غير صحيحين رغم atomic increment.
- Laravel 12 يزيد قيمة model في الذاكرة عند increment، لذلك balance_after صحيح في المسار المنفرد، لكنه ليس مضموناً عند شحنتين متزامنتين بلا wallet lock.
- gateway_response array بلا cast.
- transaction_id خاطئ عند تمرير Order response، لأنه يأخذ resource.id (Order ID).
- email queue داخل transaction.

onCaptureDeclined (358-429)
- related_ids.order_id صحيح.
- related_ids.paypal_order_id وinvoice_id كـ PayPal Order ID غير صحيحين/غير موثقين.
- لا يتحقق من status/amount/currency/custom/payee.
- البريد داخل transaction، وmail_sent يعني queued لا sent.


6. Webhook Events Flow
=======================

CHECKOUT.ORDER.APPROVED
- Order ID الصحيح: resource.id.
- local id يجب أن يطابق purchase_units[0].reference_id.
- custom_id يجب أن يساوي wallet_topup:{Payment.id}.
- يجب التحقق من status=APPROVED والمبلغ والعملة والمستفيد قبل capture.
- current controller extraction صحيح لهذا الحدث.

PAYMENT.CAPTURE.COMPLETED
- Capture ID الصحيح: resource.id.
- Order ID الصحيح: resource.supplementary_data.related_ids.order_id.
- custom_id المتوقع موجود على Capture resource عند تمريره من purchase unit، ويجب مطابقته.
- reference_id ليس مساراً أساسياً موثقاً داخل Capture webhook resource؛ يظهر في parent purchase unit داخل Order/capture response. لا يجوز افتراض وجوده في الحدث.
- يجب التحقق من resource.status=COMPLETED وresource.amount.value/currency_code وresource.payee.merchant_id.

PAYMENT.CAPTURE.DECLINED
- Capture ID: resource.id.
- Order ID: resource.supplementary_data.related_ids.order_id.
- invoice_id ليس Order ID.
- يجب ألا يحول طلب completed إلى failed؛ الكود الحالي يمنع ذلك جيداً.

Webhook مكرر
- controller الحالي يعالجه مجدداً.
- completed duplicate غالباً يتوقف عند status=completed، لكن لا يوجد event-id dedupe.
- approved duplicate يعيد capture API بلا PayPal-Request-Id وقد يفشل 422.

عدم العثور على الطلب
- controller يعيد 200 ignored؛ PayPal يتوقف عن retry، وقد يُفقد حدث مالي.
- الصحيح للأحداث المدعومة: تسجيل event وإرجاع 5xx/503 مؤقتاً أو وضعه في durable queue/reconciliation.

بقاء approved
- يحدث إذا وصل redirect ولم يصل approved webhook/capture completed، أو فشل capture.
- لا توجد reconciliation job تفحص approved القديمة: غير موجود أو لم يتم العثور عليه.


7. Database and Transaction Analysis
=====================================

المعاملات الحالية:

أ) PayPalWalletServices@pay، lines 49-110
- داخل transaction: البحث/القفل، إنشاء Payment، أحياناً showOrderDetails، createOrder، حفظ PayPal ID/response.
- rollback: أي exception من PayPal، approval link، Payment update، أو commit.
- المشكلة: PayPal Order خارجي لا يتراجع مع DB rollback.

ب) PayPalWalletServices@success، lines 115-143
- قفل Payment وتغيير pending -> approved.
- rollback عند missing row أو invalid status أو DB exception.

ج) onCaptureCompleted، lines 237-355
- البحث والقفل، Wallet create، increment، Payment update، WalletTransaction create، Redis queue، mail_sent update.
- فشل WalletTransaction يعمل rollback للرصيد وPayment، وهذه نتيجة صحيحة.
- فشل enqueue للبريد يعمل rollback للدفع، وهذه نتيجة غير صحيحة.
- قبول Redis للـ job ثم فشل commit قد يرسل بريد نجاح بلا رصيد.

د) onCaptureDeclined، lines 374-424
- قفل Payment، failed update، enqueue fail mail، mail_sent.
- فشل enqueue يلغي failed update.

ملاحظات schema الفعلي:
- payments.idempotency_key unique: موجود.
- payments.paypal_order_id unique: موجود.
- payments.transaction_id unique: موجود ويمنع Capture ID نفسه بين دفعتين إذا خُزن Capture ID الحقيقي.
- wallet_transactions.payment_id unique: غير موجود أو لم يتم العثور عليه.
- payments.wallet_credited أو wallet_credited_at: غير موجود أو لم يتم العثور عليه.
- wallet.balance unsignedInteger؛ wallet_transactions points/balances integer.
- DB_CONNECTION الحالي SQLite؛ lockForUpdate لا يوفر row-level locking الحقيقي في SQLite، لذا اختبارات التزامن على هذه البيئة لا تثبت سلوك MySQL/PostgreSQL.

Rollback بعد Capture خارجي
- إذا PayPal أكمل Capture ثم فشل WalletTransaction، DB ترجع كما كانت لكن المال دُفع.
- يجب أن يعيد Webhook أو reconciliation عملية finalization فقط، لا Capture جديداً؛ يتطلب Capture ID صحيحاً وPayPal idempotency.


8. Idempotency and Duplicate Protection
========================================

الموجود:
- frontend UUID لكل mount.
- hash user+key.
- unique idempotency_key.
- unique paypal_order_id.
- unique transaction_id.
- Payment lockForUpdate في finalization.
- status completed guard.

الناقص:
- idempotency_key required.
- payload hash ومقارنة amount/currency/user/type عند إعادة key.
- PayPal-Request-Id لـ createOrder وcapturePaymentOrder.
- unique wallet_transactions.payment_id.
- wallet_credited_at داخل نفس transaction.
- unique webhook event ID وسجل processed/failed.
- wallet row lock.

DepositSuccessMail وDepositFailMail

<?php

namespace App\Http\Controllers\api\payment;

use App\Http\Controllers\Controller;
use App\Http\Requests\Wallet\StoreDepositRequest;
use App\Models\Payment;
use App\Services\PayPalWalletServices;
use DomainException;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Log;
use Throwable;

class DepositController extends Controller
{
    public function __construct(private readonly PayPalWalletServices $paypal) {}

    public function create(StoreDepositRequest $request): JsonResponse
    {
        try {
            $result = $this->paypal->pay([
                ...$request->validated(),
                'user_id' => (int) $request->user()->getKey(),
            ]);

            return response()->json([
                'success' => true,
                'order_id' => $result['order']->id,
                'status' => $result['order']->status,
                'amount' => $result['order']->amount,
                'currency' => $result['order']->currency,
                'approval_url' => $result['approval_url'],
            ]);
        } catch (DomainException $e) {
            return response()->json(['success' => false, 'message' => $e->getMessage()], 409);
        } catch (Throwable $e) {
            Log::error('Wallet deposit creation failed', [
                'user_id' => $request->user()->id,
                'idempotency_key' => $request->string('idempotency_key')->toString(),
                'exception' => $e,
            ]);
            return response()->json(['success' => false, 'message' => 'Unable to create payment.'], 502);
        }
    }

    public function success(Request $request)
    {
        $lang = in_array($request->query('lang'), ['ar', 'en', 'ru', 'fr', 'zh'], true)
            ? $request->query('lang') : 'en';
        $token = (string) $request->query('token', '');
        if ($token === '' || strlen($token) > 64) {
            return redirect("/{$lang}/failed?error=TOKEN_MISSING");
        }

        try {
            $order = $this->paypal->success($token);
            return redirect("/{$lang}/Deposit/waiting?order_id={$order->id}");
        } catch (Throwable $e) {
            Log::error('Wallet PayPal return validation failed', [
                'token' => $request->query('token'),
                'exception' => $e,
            ]);
            return redirect("/{$lang}/failed?error=PAYPAL_RETURN_INVALID");
        }
    }

    public function cancel(Request $request)
    {
        $lang = in_array($request->query('lang'), ['ar', 'en', 'ru', 'fr', 'zh'], true)
            ? $request->query('lang') : 'en';
        return redirect("/{$lang}/failed?error=CANCELLED");
    }

    public function orderStatus(Request $request, int $id): JsonResponse
    {
        $order = Payment::query()
            ->select(['id', 'user_id', 'type', 'status', 'amount', 'currency', 'paid_at'])
            ->whereKey($id)
            ->where('user_id', $request->user()->id)
            ->where('type', 'wallet_deposit')
            ->first();

        if (! $order) {
            return response()->json(['status' => 'not_found'], 404);
        }

        return response()->json([
            'order_id' => $order->id,
            'status' => $order->status,
            'amount' => $order->amount,
            'currency' => $order->currency,
            'paid_at' => $order->paid_at?->toISOString(),
        ]);
    }
}

14.7 PayPalWalletServices مصحح (تنفيذ مرجعي كامل للمنطق المالي)

<?php

namespace App\Services;

use App\Jobs\SendDepositFailedMail;
use App\Jobs\SendDepositSuccessMail;
use App\Models\Payment;
use App\Models\Wallet;
use App\Models\WalletTransaction;
use Carbon\CarbonImmutable;
use DomainException;
use Illuminate\Database\UniqueConstraintViolationException;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Str;
use RuntimeException;
use Srmklive\PayPal\Services\PayPal as PayPalClient;
use Throwable;

class PayPalWalletServices
{
    private ?PayPalClient $client = null;

    private function provider(): PayPalClient
    {
        if ($this->client) {
            return $this->client;
        }
        $this->client = new PayPalClient;
        $this->client->setApiCredentials(config('paypal'));
        $this->client->getAccessToken();
        $this->client->setRequestHeader('Prefer', 'return=representation');
        return $this->client;
    }

    public function pay(array $data): array
    {
        $amount = $this->money((string) $data['amount']);
        $currency = strtoupper((string) config('paypal.currency', 'USD'));
        $key = hash('sha256', $data['user_id'].'|'.$data['idempotency_key']);
        $payloadHash = hash('sha256', json_encode([
            'user_id' => (int) $data['user_id'],
            'amount' => $amount,
            'currency' => $currency,
            'type' => 'wallet_deposit',
        ], JSON_THROW_ON_ERROR));

        $order = $this->getOrCreateLocalPayment($data, $key, $payloadHash, $amount, $currency);
        $this->assertIdempotentPayload($order, $payloadHash);

        if ($order->status === 'completed') {
            return ['order' => $order, 'approval_url' => null];
        }
        if ($order->status === 'failed') {
            throw new DomainException('This idempotency key belongs to a failed payment. Use a new key.');
        }

        if ($order->paypal_order_id) {
            return $this->resumeExistingOrder($order);
        }

        $paypalOrder = $this->provider()
            ->withIdempotencyKey('wallet-create-'.$order->id)
            ->createOrder([
                'intent' => 'CAPTURE',
                'application_context' => [
                    'return_url' => route('wallet.success', ['lang' => $data['locale']]),
                    'cancel_url' => route('wallet.cancel', ['lang' => $data['locale'], 'order_id' => $order->id]),
                ],
                'purchase_units' => [[
                    'reference_id' => (string) $order->id,
                    'custom_id' => 'wallet_topup:'.$order->id,
                    'amount' => ['currency_code' => $currency, 'value' => $amount],
                    'description' => $order->description,
                ]],
            ]);

        if (! isset($paypalOrder['id']) || ($paypalOrder['status'] ?? null) !== 'CREATED') {
            throw new RuntimeException('PayPal did not create the order.');
        }
        $this->assertOrderResource($order, $paypalOrder, ['CREATED']);

        $order = DB::transaction(function () use ($order, $paypalOrder) {
            $locked = Payment::whereKey($order->id)->lockForUpdate()->firstOrFail();
            if ($locked->paypal_order_id && $locked->paypal_order_id !== $paypalOrder['id']) {
                throw new RuntimeException('Conflicting PayPal order IDs.');
            }
            $locked->update([
                'paypal_order_id' => $paypalOrder['id'],
                'gateway_response' => $paypalOrder,
            ]);
            return $locked->fresh();
        }, 3);

        return ['order' => $order, 'approval_url' => $this->approvalUrl($paypalOrder)];
    }

    private function getOrCreateLocalPayment(
        array $data,
        string $key,
        string $payloadHash,
        string $amount,
        string $currency
    ): Payment {
        try {
            return DB::transaction(function () use ($data, $key, $payloadHash, $amount, $currency) {
                $existing = Payment::where('idempotency_key', $key)->lockForUpdate()->first();
                if ($existing) {
                    return $existing;
                }
                return Payment::create([
                    'idempotency_key' => $key,
                    'payload_hash' => $payloadHash,
                    'user_id' => (int) $data['user_id'],
                    'amount' => $amount,
                    'points' => $this->amountToPoints($amount),
                    'currency' => $currency,
                    'description' => $data['description'] ?: 'Wallet Deposit',
                    'type' => 'wallet_deposit',
                    'status' => 'pending',
                    'payment_method' => 'paypal',
                ]);
            }, 3);
        } catch (UniqueConstraintViolationException $e) {
            return Payment::where('idempotency_key', $key)->firstOrFail();
        }
    }

    private function assertIdempotentPayload(Payment $order, string $payloadHash): void
    {
        if (! $order->payload_hash || ! hash_equals($order->payload_hash, $payloadHash)) {
            throw new DomainException('The idempotency key was already used with different payment data.');
        }
    }

    private function resumeExistingOrder(Payment $order): array
    {
        $details = $this->provider()->showOrderDetails($order->paypal_order_id);
        $this->assertOrderResource($order, $details, ['CREATED', 'APPROVED', 'COMPLETED']);
        $status = $details['status'];
        if ($status === 'CREATED') {
            return ['order' => $order, 'approval_url' => $this->approvalUrl($details)];
        }
        if ($status === 'APPROVED') {
            $this->markApproved($order->id);
            $this->captureApprovedPayment($order->fresh());
        } else {
            $this->finalizeOrderResponse($order, $details);
        }
        return ['order' => $order->fresh(), 'approval_url' => null];
    }

    public function success(string $paypalOrderId): Payment
    {
        $order = Payment::where('paypal_order_id', $paypalOrderId)
            ->where('type', 'wallet_deposit')->firstOrFail();
        if ($order->status === 'completed') {
            return $order;
        }

        $details = $this->provider()->showOrderDetails($paypalOrderId);
        $this->assertOrderResource($order, $details, ['APPROVED', 'COMPLETED']);
        if ($details['status'] === 'APPROVED') {
            $this->markApproved($order->id);
            $this->captureApprovedPayment($order->fresh());
        } else {
            $this->finalizeOrderResponse($order, $details);
        }
        return $order->fresh();
    }

    public function handleWebhook(array $payload): void
    {
        $resource = $payload['resource'] ?? [];
        match ($payload['event_type'] ?? '') {
            'CHECKOUT.ORDER.APPROVED' => $this->onOrderApproved($resource),
            'PAYMENT.CAPTURE.COMPLETED' => $this->finalizeCaptureResource($resource),
            'PAYMENT.CAPTURE.DECLINED' => $this->onCaptureDeclined($resource),
            default => null,
        };
    }

    private function onOrderApproved(array $resource): void
    {
        $paypalOrderId = $resource['id'] ?? null;
        if (! $paypalOrderId) {
            throw new RuntimeException('Approved event is missing the PayPal order ID.');
        }
        $order = Payment::where('paypal_order_id', $paypalOrderId)
            ->where('type', 'wallet_deposit')->firstOrFail();
        $this->assertOrderResource($order, $resource, ['APPROVED']);
        $this->markApproved($order->id);
        $this->captureApprovedPayment($order->fresh());
    }

    private function markApproved(int $paymentId): void
    {
        DB::transaction(function () use ($paymentId) {
            $order = Payment::whereKey($paymentId)->lockForUpdate()->firstOrFail();
            if ($order->status === 'pending') {
                $order->update(['status' => 'approved']);
            }
        }, 3);
    }

    private function captureApprovedPayment(Payment $order): void
    {
        if ($order->status === 'completed') {
            $this->queueSuccessMail($order);
            return;
        }
        try {
            $response = $this->provider()
                ->withIdempotencyKey('wallet-capture-'.$order->id)
                ->capturePaymentOrder($order->paypal_order_id);
        } catch (Throwable $e) {
            $details = $this->provider()->showOrderDetails($order->paypal_order_id);
            if (($details['status'] ?? null) !== 'COMPLETED') {
                throw $e;
            }
            $response = $details;
        }

        if (($response['status'] ?? null) === 'COMPLETED') {
            $this->finalizeOrderResponse($order, $response);
            return;
        }
        if (($response['status'] ?? null) !== 'APPROVED') {
            throw new RuntimeException('Capture returned a non-recoverable status.');
        }
    }

    private function finalizeOrderResponse(Payment $order, array $response): void
    {
        $unit = $response['purchase_units'][0] ?? [];
        $capture = $unit['payments']['captures'][0] ?? null;
        if (! is_array($capture)) {
            throw new RuntimeException('Completed PayPal order has no capture resource.');
        }
        $capture['supplementary_data']['related_ids']['order_id'] ??= $response['id'] ?? null;
        $capture['custom_id'] ??= $unit['custom_id'] ?? null;
        $capture['payee'] ??= $unit['payee'] ?? null;
        $this->finalizeCaptureResource($capture, $unit['reference_id'] ?? null);
    }

    private function finalizeCaptureResource(array $resource, ?string $referenceId = null): void
    {
        $paypalOrderId = $resource['supplementary_data']['related_ids']['order_id'] ?? null;
        $captureId = $resource['id'] ?? null;
        $customId = $resource['custom_id'] ?? null;
        if (! $captureId || ! $paypalOrderId) {
            throw new RuntimeException('Capture is missing capture/order identifiers.');
        }

        $order = Payment::where('paypal_order_id', $paypalOrderId)
            ->where('type', 'wallet_deposit')->firstOrFail();
        $this->assertCaptureResource($order, $resource, $referenceId);

        $order = DB::transaction(function () use ($order, $resource, $captureId) {
            $locked = Payment::whereKey($order->id)->lockForUpdate()->firstOrFail();
            if ($locked->status === 'completed' || $locked->wallet_credited_at) {
                if ($locked->transaction_id !== $captureId || ! $locked->walletTransaction()->exists()) {
                    throw new RuntimeException('Completed payment has inconsistent capture/ledger data.');
                }
                return $locked;
            }

            $captureOwner = Payment::where('transaction_id', $captureId)
                ->whereKeyNot($locked->id)->exists();
            if ($captureOwner) {
                throw new RuntimeException('Capture ID was already used by another payment.');
            }

            Wallet::query()->insertOrIgnore([
                'user_id' => $locked->user_id,
                'uuid' => (string) Str::uuid(),
                'balance' => 0,
                'payback_balance' => 0,
                'is_active' => true,
                'created_at' => now(),
                'updated_at' => now(),
            ]);
            $wallet = Wallet::withTrashed()->where('user_id', $locked->user_id)
                ->lockForUpdate()->firstOrFail();
            if ($wallet->trashed()) {
                $wallet->restore();
            }

            $points = (int) $locked->points;
            $before = (int) $wallet->balance;
            if ($points <= 0 || $before > PHP_INT_MAX - $points) {
                throw new RuntimeException('Wallet points overflow.');
            }
            $after = $before + $points;
            $wallet->forceFill(['balance' => $after])->save();

            WalletTransaction::create([
                'user_id' => $locked->user_id,
                'wallet_id' => $wallet->id,
                'payment_id' => $locked->id,
                'points' => $points,
                'type' => 'credit',
                'description' => 'PayPal wallet deposit',
                'balance_before' => $before,
                'balance_after' => $after,
                'slug' => $locked->idempotency_key,
            ]);

            $locked->update([
                'status' => 'completed',
                'transaction_id' => $captureId,
                'gateway_response' => $resource,
                'paid_at' => isset($resource['update_time'])
                    ? CarbonImmutable::parse($resource['update_time']) : now(),
                'wallet_credited_at' => now(),
                'mail_sent' => false,
                'mail_sent_at' => null,
            ]);
            return $locked->fresh();
        }, 3);

        DB::afterCommit(function () use ($order) {
            Cache::tags(['wallet', 'transactions', "user_{$order->user_id}"])->flush();
        });
        $this->queueSuccessMail($order);
    }

    private function onCaptureDeclined(array $resource): void
    {
        if (($resource['status'] ?? null) !== 'DECLINED') {
            throw new RuntimeException('Declined event resource is not DECLINED.');
        }
        $paypalOrderId = $resource['supplementary_data']['related_ids']['order_id'] ?? null;
        $order = Payment::where('paypal_order_id', $paypalOrderId)
            ->where('type', 'wallet_deposit')->firstOrFail();
        $this->assertCaptureIdentityAndMoney($order, $resource, null);

        $order = DB::transaction(function () use ($order, $resource) {
            $locked = Payment::whereKey($order->id)->lockForUpdate()->firstOrFail();
            if ($locked->status !== 'completed') {
                $locked->update(['status' => 'failed', 'gateway_response' => $resource]);
            }
            return $locked->fresh();
        }, 3);
        if ($order->status === 'failed' && ! $order->mail_sent) {
            SendDepositFailedMail::dispatch($order->id)->afterCommit();
        }
    }

    private function assertOrderResource(Payment $order, array $resource, array $statuses): void
    {
        if (($resource['id'] ?? null) && $order->paypal_order_id
            && $resource['id'] !== $order->paypal_order_id) {
            throw new RuntimeException('PayPal order ID mismatch.');
        }
        if (! in_array($resource['status'] ?? null, $statuses, true)) {
            throw new RuntimeException('Unexpected PayPal order status.');
        }
        $unit = $resource['purchase_units'][0] ?? [];
        if (($unit['reference_id'] ?? null) !== (string) $order->id
            || ($unit['custom_id'] ?? null) !== 'wallet_topup:'.$order->id) {
            throw new RuntimeException('PayPal order reference/custom ID mismatch.');
        }
        $this->assertMoneyAndMerchant($order, $unit['amount'] ?? [], $unit['payee'] ?? []);
    }

    private function assertCaptureResource(Payment $order, array $resource, ?string $referenceId): void
    {
        if (($resource['status'] ?? null) !== 'COMPLETED') {
            throw new RuntimeException('Capture is not COMPLETED.');
        }
        $this->assertCaptureIdentityAndMoney($order, $resource, $referenceId);
    }

    private function assertCaptureIdentityAndMoney(Payment $order, array $resource, ?string $referenceId): void
    {
        $relatedOrderId = $resource['supplementary_data']['related_ids']['order_id'] ?? null;
        if ($relatedOrderId !== $order->paypal_order_id
            || ($resource['custom_id'] ?? null) !== 'wallet_topup:'.$order->id
            || ($referenceId !== null && $referenceId !== (string) $order->id)
            || $order->type !== 'wallet_deposit'
            || ! $order->user_id) {
            throw new RuntimeException('Capture identity mismatch.');
        }
        $this->assertMoneyAndMerchant($order, $resource['amount'] ?? [], $resource['payee'] ?? []);
    }

    private function assertMoneyAndMerchant(Payment $order, array $amount, array $payee): void
    {
        if ($this->money((string) ($amount['value'] ?? '')) !== $this->money((string) $order->amount)
            || strtoupper((string) ($amount['currency_code'] ?? '')) !== strtoupper($order->currency)) {
            throw new RuntimeException('PayPal amount/currency mismatch.');
        }
        $expectedMerchant = (string) config('paypal.merchant_id');
        if ($expectedMerchant === '' || ($payee['merchant_id'] ?? null) !== $expectedMerchant) {
            throw new RuntimeException('PayPal beneficiary merchant mismatch or not configured.');
        }
    }

    private function queueSuccessMail(Payment $order): void
    {
        if (! $order->mail_sent) {
            SendDepositSuccessMail::dispatch($order->id)->afterCommit();
        }
    }

    private function approvalUrl(array $order): string
    {
        $link = collect($order['links'] ?? [])->firstWhere('rel', 'approve');
        $url = is_array($link) ? ($link['href'] ?? null) : null;
        if (! is_string($url) || $url === '') {
            throw new RuntimeException('PayPal approval URL is missing.');
        }
        return $url;
    }

    private function money(string $value): string
    {
        if (! preg_match('/^\d+(?:\.\d{1,2})?$/', $value)) {
            throw new RuntimeException('Invalid money format.');
        }
        [$whole, $fraction] = array_pad(explode('.', $value, 2), 2, '');
        $whole = ltrim($whole, '0');
        $whole = $whole === '' ? '0' : $whole;
        return $whole.'.'.str_pad($fraction, 2, '0');
    }

    private function amountToPoints(string $amount): int
    {
        [$whole, $cents] = explode('.', $this->money($amount));
        $pointsPerUsd = (int) config('wallet.points_per_usd', 1_000_000);
        if ($pointsPerUsd <= 0 || $pointsPerUsd % 100 !== 0) {
            throw new RuntimeException('WALLET_POINTS_PER_USD must be positive and divisible by 100.');
        }
        return ((int) $whole * $pointsPerUsd) + ((int) $cents * intdiv($pointsPerUsd, 100));
    }
}

14.8 WebhookController مصحح بالكامل

<?php

namespace App\Http\Controllers\api\webhook;

use App\Http\Controllers\Controller;
use App\Models\Payment;
use App\Models\PaypalWebhookEvent;
use App\Services\PayPalServices;
use App\Services\PayPalWalletServices;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;
use Srmklive\PayPal\Services\PayPal as PayPalClient;
use Throwable;

class WebhookController extends Controller
{
    private const TYPES = [
        'CHECKOUT.ORDER.APPROVED',
        'PAYMENT.CAPTURE.COMPLETED',
        'PAYMENT.CAPTURE.DECLINED',
    ];

    public function handle(Request $request)
    {
        $body = $request->getContent();
        $event = json_decode($body, true);
        if (! is_array($event)) {
            return response()->json(['error' => 'invalid_json'], 400);
        }

        $required = [
            'PAYPAL-TRANSMISSION-ID', 'PAYPAL-TRANSMISSION-TIME',
            'PAYPAL-CERT-URL', 'PAYPAL-AUTH-ALGO', 'PAYPAL-TRANSMISSION-SIG',
        ];
        foreach ($required as $header) {
            if (! $request->hasHeader($header) || $request->header($header) === '') {
                return response()->json(['error' => 'missing_signature_headers'], 400);
            }
        }
        if (! config('paypal.webhook_id')) {
            return response()->json(['error' => 'webhook_not_configured'], 500);
        }

        try {
            $provider = new PayPalClient;
            $provider->setApiCredentials(config('paypal'));
            $provider->getAccessToken();
            $verification = $provider->verifyWebHook([
                'transmission_id' => $request->header('PAYPAL-TRANSMISSION-ID'),
                'transmission_time' => $request->header('PAYPAL-TRANSMISSION-TIME'),
                'cert_url' => $request->header('PAYPAL-CERT-URL'),
                'auth_algo' => $request->header('PAYPAL-AUTH-ALGO'),
                'transmission_sig' => $request->header('PAYPAL-TRANSMISSION-SIG'),
                'webhook_id' => config('paypal.webhook_id'),
                'webhook_event' => json_decode($body),
            ]);
            if (($verification['verification_status'] ?? null) !== 'SUCCESS') {
                return response()->json(['error' => 'invalid_signature'], 400);
            }
        } catch (Throwable $e) {
            Log::error('PayPal webhook verification unavailable', ['exception' => $e]);
            return response()->json(['error' => 'verification_unavailable'], 503);
        }

        $eventId = $event['id'] ?? null;
        $eventType = $event['event_type'] ?? null;
        if (! is_string($eventId) || ! in_array($eventType, self::TYPES, true)) {
            return response()->json(['status' => 'ignored'], 200);
        }
        $paypalOrderId = $this->extractPaypalOrderId($event);
        if (! $paypalOrderId) {
            return response()->json(['error' => 'missing_order_id'], 422);
        }

        $record = PaypalWebhookEvent::firstOrCreate(
            ['event_id' => $eventId],
            ['event_type' => $eventType, 'paypal_order_id' => $paypalOrderId,
             'status' => 'received', 'payload' => $event]
        );
        $claim = DB::transaction(function () use ($record) {
            $locked = PaypalWebhookEvent::whereKey($record->id)->lockForUpdate()->firstOrFail();
            if ($locked->status === 'processed') {
                return 'duplicate';
            }
            if ($locked->status === 'processing' && $locked->updated_at->gt(now()->subMinutes(5))) {
                return 'busy';
            }
            $locked->update(['status' => 'processing', 'attempts' => $locked->attempts + 1, 'last_error' => null]);
            return 'claimed';
        });
        if ($claim === 'duplicate') {
            return response()->json(['status' => 'duplicate'], 200);
        }
        if ($claim === 'busy') {
            return response()->json(['status' => 'processing'], 503);
        }

        try {
            $payment = Payment::where('paypal_order_id', $paypalOrderId)->first();
            if (! $payment) {
                throw new \RuntimeException('Payment not found yet.');
            }
            if ($payment->type === 'wallet_deposit') {
                app(PayPalWalletServices::class)->handleWebhook($event);
            } else {
                app(PayPalServices::class)->handleWebhook($event);
            }
            $record->update(['status' => 'processed', 'processed_at' => now()]);
            return response()->json(['status' => 'ok'], 200);
        } catch (Throwable $e) {
            $record->update(['status' => 'failed', 'last_error' => mb_substr($e->getMessage(), 0, 2000)]);
            Log::error('PayPal webhook processing failed', [
                'event_id' => $eventId, 'event_type' => $eventType,
                'paypal_order_id' => $paypalOrderId, 'exception' => $e,
            ]);
            return response()->json(['error' => 'processing_failed'], 503);
        }
    }

    private function extractPaypalOrderId(array $event): ?string
    {
        $resource = $event['resource'] ?? [];
        return match ($event['event_type'] ?? null) {
            'CHECKOUT.ORDER.APPROVED' => $resource['id'] ?? null,
            'PAYMENT.CAPTURE.COMPLETED', 'PAYMENT.CAPTURE.DECLINED'
                => $resource['supplementary_data']['related_ids']['order_id'] ?? null,
            default => null,
        };
    }
}

14.10 charge.vue: استبدال script setup

<script setup>
import { computed, ref } from 'vue'
import { useI18n } from 'vue-i18n'
import { useRouter } from 'vue-router'
import { v4 as uuidv4 } from 'uuid'
import api from '@/services/ApiClient'
import homeService from '@/services/home/homeService'

const props = defineProps({ wallet: { type: Object, default: null } })
const router = useRouter()
const { t } = useI18n()
const storageKey = 'wallet_deposit_idempotency_key'
const idempotencyKey = ref(sessionStorage.getItem(storageKey) || uuidv4())
sessionStorage.setItem(storageKey, idempotencyKey.value)

const presets = [10, 25, 50, 100]
const selectedPreset = ref(null)
const loading = ref(false)
const serverError = ref('')
const form = ref({ amount: '', description: '' })

const amountError = computed(() => {
    const value = Number(form.value.amount)
    if (!form.value.amount) return ''
    if (!Number.isFinite(value) || value < 1 || value > 999999.99) return t('user.charge.amountError')
    if (!/^\d+(\.\d{1,2})?$/.test(String(form.value.amount))) return t('user.charge.amountError')
    return ''
})
const isValid = computed(() => form.value.amount !== '' && !amountError.value)

function selectPreset(value) {
    selectedPreset.value = value
    form.value.amount = value
}

async function handlePay() {
    if (!isValid.value || loading.value) return
    loading.value = true
    serverError.value = ''
    try {
        const { data } = await api.post('/deposit/pay', {
            amount: String(form.value.amount),
            description: form.value.description || t('user.charge.defaultDescription'),
            idempotency_key: idempotencyKey.value,
            locale: homeService.getLang(),
        })
        if (!data?.order_id) throw new Error('Missing order_id')
        if (data.approval_url) {
            sessionStorage.removeItem(storageKey)
            window.location.assign(data.approval_url)
            return
        }
        if (data.status === 'completed') {
            sessionStorage.removeItem(storageKey)
            await router.replace(`/${homeService.getLang()}/deposit/success?order_id=${data.order_id}`)
            return
        }
        await router.replace(`/${homeService.getLang()}/Deposit/waiting?order_id=${data.order_id}`)
    } catch (error) {
        serverError.value = error.response?.data?.message || t('user.charge.genericError')
    } finally {
        loading.value = false
    }
}
</script>

14.11 WaitingDeposit.vue: استبدال script setup
------------------------------------------------
<script setup>
import { computed, onMounted, onUnmounted, ref } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { useI18n } from 'vue-i18n'
import api from '@/services/ApiClient'
import homeService from '@/services/home/homeService'

const route = useRoute()
const router = useRouter()
const { locale } = useI18n()
const orderId = String(route.query.order_id || '')
const attempts = ref(0)
const MAX_ATTEMPTS = 30
const POLL_DELAY_MS = 5000
let timer = null
let controller = null
let stopped = false
let isChecking = false

const currentLang = () => homeService.getLang()

function stop() {
    stopped = true
    if (timer) clearTimeout(timer)
    timer = null
    controller?.abort()
}

async function finish(path) {
    stop()
    await router.replace(path)
}

function schedule() {
    if (!stopped) timer = setTimeout(checkStatus, POLL_DELAY_MS)
}

async function checkStatus() {
    if (stopped || isChecking) return
    if (attempts.value >= MAX_ATTEMPTS) {
        await finish(`/${currentLang()}/failed?error=POLL_TIMEOUT`)
        return
    }
    isChecking = true
    attempts.value += 1
    controller = new AbortController()
    try {
        const { data } = await api.get(`/wallet/order-status/${encodeURIComponent(orderId)}`, {
            signal: controller.signal,
        })
        if (data.status === 'completed') {
            await finish(`/${currentLang()}/deposit/success?order_id=${data.order_id}`)
            return
        }
        if (data.status === 'failed') {
            await finish(`/${currentLang()}/failed?error=PAYMENT_FAILED`)
            return
        }
        if (!['pending', 'approved'].includes(data.status)) {
            await finish(`/${currentLang()}/failed?error=UNKNOWN_STATUS`)
            return
        }
    } catch (error) {
        if (error.name === 'CanceledError') return
        if (error.response?.status === 401) {
            await finish(`/${currentLang()}/auth`)
            return
        }
        if (error.response?.status === 404 && attempts.value >= 3) {
            await finish(`/${currentLang()}/failed?error=ORDER_NOT_FOUND`)
            return
        }
    } finally {
        isChecking = false
        if (!stopped) schedule()
    }
}

onMounted(() => {
    locale.value = currentLang()
    if (!/^\d+$/.test(orderId)) {
        finish(`/${currentLang()}/failed?error=ORDER_ID_MISSING`)
        return
    }
    checkStatus()
})

onUnmounted(stop)
</script>

15. Final End-to-End Flow
==========================

User
→ POST /api/v1/deposit/pay مع Bearer token وUUID وamount مضبوط
→ StoreDepositRequest يثبت decimal/locale/description
→ DepositController@create
→ PayPalWalletServices@pay
→ Payment pending + points + payload_hash داخل transaction قصيرة
→ PayPal createOrder خارج transaction مع PayPal-Request-Id ثابت
→ reference_id/custom_id/amount/currency محفوظون ومطابقون
→ paypal_order_id وgateway_response محفوظان بـ JSON cast
→ approval_url returned
→ User approves payment
→ قد يصل /wallet/success أو CHECKOUT.ORDER.APPROVED أولاً
→ كل قناة تتحقق server-to-server من Order APPROVED
→ capturePaymentOrder مع PayPal-Request-Id ثابت
→ Capture response أو verified PAYMENT.CAPTURE.COMPLETED
→ تحقق COMPLETED + order id + capture id + custom id + reference عند توفره + amount + currency + merchant
→ DB transaction: lock Payment ثم Wallet
→ رفض Capture ID مستخدم
→ Wallet balance updated as BIGINT
→ WalletTransaction unique(payment_id) created
→ Payment status=completed + transaction_id=Capture ID + wallet_credited_at
→ Commit
→ cache invalidation وmail job afterCommit
→ Webhook event marked processed
→ Frontend sequential polling receives completed
→ Redirect to success page with real local order_id

إذا فشل WalletTransaction
→ transaction rollback؛ لا رصيد ولا completed محلياً
→ Webhook يرجع 503؛ event status=failed
→ PayPal/reconciliation يعيد finalization بنفس Capture، ولا يعمل Capture جديداً.

إذا فشل البريد
→ payment والرصيد يظلان committed
→ Job retries؛ mail_sent يبقى false حتى نجاح النقل.
